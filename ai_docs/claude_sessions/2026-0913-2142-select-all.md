# Select all — one verb, three doors

Session: `session_01TjQmoBE2A5JJ7Nj6ytWVSM`
(https://claude.ai/code/session_01TjQmoBE2A5JJ7Nj6ytWVSM)

Date: 2026-09-13

## What was asked

> Need a Select All (in file). Add it to the in focus file's context menu
> and to the File | Edit and the Command Palette

"File | Edit" was read as the ≡ menu's **Edit** group (where Copy / Cut /
Paste live). The command palette gets every ≡ row for free, so no separate
palette wiring was needed.

## What already existed

`editor.Tab.SelectAll()` (internal/editor/tab.go) — anchor at 0:0, cursor
at `Buffer.EndPos()`, secondary carets dropped, `cursorMoved` set, undo
group broken. Its only caller was the plugin whole-file replace
(plugincmd.go). No UI surface reached it, and `metaReserved()` in
metakeys.go does not bind ⌘A.

## What changed

- **internal/app/app.go**
  - ≡ Edit group: `{label: "Select all", action: menuSelectAll, enabled:
    hasSelectableTab}` directly after Paste — beside the clipboard verbs it
    feeds. No shortcut column (no leader key: the flat table is out of
    mnemonic letters).
  - `menuSelectAll` — closes the menu, calls `selectAllInFile`.
  - `selectAllInFile` — the ONE implementation behind the ≡ row, the
    palette entry and the right-click row, so they can't disagree about
    what "all" covers. Refuses what the predicate dims.
  - `hasSelectableTab` — tab exists, not an image, has a Buffer, and is
    NOT in markdown preview. Preview is excluded deliberately: there is no
    visible caret or selection there, and a selection made in a preview
    would silently become the argument of the next Cut after flipping back
    to source.
- **internal/app/contextmenu.go** — `"Select all"` in the fixed vocabulary
  after Paste, `enabled: alwaysTrue`. Safe because the popup only opens over
  a source-view text tab (`tryEditorContextClick` declines image/nil-buffer
  tabs and routes previews to `openPreviewContext`).
- **Pins bumped** (one new ≡ row): `TestMenuLayout_NoCustomActions` 155 → 156
  rows (139 group actions), height 161 → 162, dividers `[2,5,158]` →
  `[2,5,159]`; `TestMenuLayout_WithCustomActions` height 164 → 165.
  CLAUDE.md's copy of those numbers updated to match.

## Tests added

- `TestMenuSelectAll` (app_test.go) — dimmed with no tab; enabled on a text
  tab; selects the whole buffer and drops a secondary caret; dimmed in a
  markdown preview and `selectAllInFile` makes no selection there.
- `TestEditorContextSelectAllRow` (contextmenu_test.go) — row present and
  enabled; activating it closes the popup and selects the whole buffer even
  though the right-click itself had just collapsed the selection by moving
  the caret.

`go vet ./internal/app/` clean; `go test ./internal/app/` passes.
