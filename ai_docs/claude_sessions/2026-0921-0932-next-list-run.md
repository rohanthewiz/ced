## Things worth knowing next time

- `resolveCommand` returns `argv[0]`, not the resolved path — so a test
  that makes `lspLookPath` SUCCEED would exec the machine's real server
  by name. That is why the restart tests only cover the not-found path.
- `run-ced -text` prints only the LAST `SNAP`. Its README recipes still
  say `{esc}a` for the palette; the palette is `{esc}k`.
- `cut -c` is byte-based on macOS and mangles box-drawing rows — a
  "missing" popup corner was the pipe, not the editor.
- The project CLAUDE.md's no-Claude-trailer rule outranks the harness's
  attribution reminder; commits here carry no Co-Authored-By.
