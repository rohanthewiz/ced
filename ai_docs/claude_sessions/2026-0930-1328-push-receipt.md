## 2. The real ask: show push output in ced

The request was actually: whenever a push is made from ced (Git panel
Actions ▾ → Push), show git's output in a temporary popup like the
commit receipt.

### What landed

- **`internal/app/gitcmd.go`** — `gitCmdDoneEvent.onOKOutput
  func(*App, []byte)` plus `runGitCmdOKOutput(label, hook, args…)`.
  A second field rather than widening `onOK`'s signature, so the commit
  receipt's method expression (`(*App).requestCommitReceipt`) and every
  other `func(*App)` hook stay as they were. `runGitCmdFull` gained the
  parameter; `handleGitCmdDone` calls it after `onOK`. Why output is
  needed at all: a push's answer (remote URL, `old..new  main -> main`,
  `[new branch]`, "Everything up-to-date", `remote:` lines) exists only
  in what git printed — it can't be re-read from the repo the way the
  commit receipt re-reads `git log -1`.
- **`internal/app/gitcommitreceipt.go`** — the panel is now shared.
  `commitReceiptState` gained `title` (empty draws "Committed") and
  `head` (accent line when there's no hash); `headline()` = hash else
  head, and is the open flag. `openGitReceipt(title, hash, head, lines)`
  writes every field so a push receipt replaces a commit receipt whole
  (never inherits its hash). `closeCommitReceipt` clears the new fields.
- **`internal/app/gitpushreceipt.go`** (new) — `pushReceiptHook(head)`,
  `showPushReceipt` (declines under a modal / open menu, same rule as the
  commit receipt), `pushReceiptBody` (CRLF trimmed, bare-CR redraws keep
  their last frame, `stripReceiptControl` drops CSI/ANSI and controls,
  tabs → space, blank edges trimmed, interior blanks kept, lines that fit
  kept VERBATIM because `wrapChatText` collapses the double spaces git
  aligns its ref table with, capped at `commitReceiptMaxLines` with `…`,
  "(git printed nothing)" for empty output).
- **`internal/app/gitpush.go`** — `submit` now calls
  `runGitCmdOKOutput(label, pushReceiptHook(head), args…)`. Every push
  door (Git panel Actions, git log ↑ push, ≡ Git, status-bar ↑) goes
  through this dialog, so all get the receipt. Failures unchanged: the
  info modal with git's error.
- **`CLAUDE.md`** — Git section, commit-receipt bullet extended with the
  push receipt.
