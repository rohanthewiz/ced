## 1. The ask

From the cats-todo backlog:

> Tab Groups support
> - Allow up to a 4 letter name
> - Group by Folder or Adhoc
> - Context menu on Group for Group mgmt
> - Group can be created from a file tab's context menu item "Add to Group"

## 2. What landed

**`internal/app/tabgroups.go`** (new). The header explains every design
choice.

- **Names**: 1–4 letters or digits, unique case-insensitively
  (`tabGroupNameProblem`). A refused name flashes the reason and re-asks
  with what was typed. Seeds: a folder group gets the first four
  letters of the folder's name (`tabGroupNameFrom`), an ad-hoc group
  gets `grp`. A digit is added when the seed is taken
  (`uniqueTabGroupName`: `api` → `api2`).
- **Kinds**:
  - FOLDER group (`folder` set): a rule. Every open file under the
    folder belongs, including files opened later. `exclude` holds the
    tabs removed by hand.
  - AD-HOC group: `members`.
- **Membership**:
  - Keyed by `*editor.Tab`, so a rename keeps the tab in its group and
    untitled tabs can join.
  - Resolved by `tabGroupOf`: ad-hoc membership first, then the
    deepest folder group.
  - `addTabToGroup` excludes the tab from DEEPER folder groups only, so
    the pick wins and no stale exclusion is left on shallower ones.
  - `tabGroupsForgetTab` runs in `closeTab`. An empty ad-hoc group goes
    with its last tab; folder groups stay.
- **Contiguity**: `arrangeTabGroups` REORDERS `a.tabs`. Each group
  clusters at its first member's position; the pass is stable and
  idempotent, and a no-op with no groups. It runs at the top of
  `layoutTabs`, and the active tab is followed by pointer. Esc , / Esc .,
  the switcher and `+N` therefore agree with the drawn order.
- **Strip** (`tabbar.go`):
  - The chip is part of its tab's slot: `tabSlotWidth(i, first)` =
    chip + body, and `tabWidth`'s old body math is now `tabBodyWidth`.
    `tabScroll` stays a tab index. The first DRAWN member carries the
    chip, so a strip scrolled into a group still names it.
  - `tabRect` gains `ChipX/ChipW/Group`. Folded tabs get zero-width
    rects, so `+N` counts only tabs scrolled off the strip.
  - Collapse never hides the active tab. The chip shows ` api +N `,
    where N is how many tabs the fold hides.
  - Chip colour comes from six syntax-palette hues, read at paint time.
    The chip text is BG or Text, whichever contrasts more.
  - Member tabs get a PLAIN underline (see §4).
- **Doors**:
  - Chip left click: fold / unfold. Chip right click: the group menu
    (`tabGroupContextItems`): Collapse/Expand · Switch to a tab in
    group… · Rename group… · Make ad-hoc group (folder groups only;
    freezes the current members) · Close group's tabs (keeps unsaved
    tabs) · Ungroup.
  - Tab menu: "Add to group…" is a picker listing the groups that can
    take the tab, "New ad-hoc group…" and "New folder group: <dir>/".
    "Remove from group <name>" appears only on a grouped tab.
  - ≡ File: "Add tab to group…" (active tab) and "Tab groups…" (a
    picker of groups → a picker of the same menu rows). "Tab groups…"
    flashes how to make a group when there are none.
- **Session**: `session.TabGroup` on `Entry.Groups`, stored by path;
  `trimGroups` drops nameless groups and ad-hoc groups with no members.
  `recordSession` encodes the groups. `restoreSession` DEFERS
  `restoreTabGroups`, so it runs after the tabs reopen and also on the
  no-tabs early return (a folder group still comes back).

## 4. Decisions and findings

- **Coloured underline dropped for a plain one.** tcell emits the
  underline colour as the colon form `58:2::R:G:B`. The run-ced
  emulator splits SGR on `;` only, so it read that as `0` (a reset) and
  wiped the member tabs' colours. A real terminal that splits colons the
  same way would show stray colour codes. ced emits SGR 58 nowhere
  else. The chip already says which group; the underline only says how
  far it runs.
- **The run-ced skill's recipes are stale**: they open the palette with
  `Esc a`, but `Esc a` is the AI namespace and the palette is `Esc k`.
  The first capture typed "Add tab to group" into a buffer (N-041).
