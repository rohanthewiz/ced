## Starting point

A probe over `builtinMenuGroups` (labels resolved on `newTestApp`)
against README.md found **94 of ~190 ≡ rows** not mentioned anywhere.
Of the 25 `config.json` keys (`userconfig.fileFormat` tags), **9** had
no mention at all (icons, autosave, termdock, findalldock, blamestyle,
execmarks, treeautofit, remote, session), and there was no config
reference. The `### Tool windows` section named its panels only in a
prose sentence.

Prose itself can't be pinned mechanically, so the work went into the
surfaces that CAN be enumerated from code: ≡ rows, tool windows, config
keys — each as a README reference table with a both-ways test (a row
missing, or a row naming something that no longer exists).

## What changed

### `internal/readme` (new package, test-only consumer)

One parser shared by every README pin, so a Markdown quirk is handled
once: `Parse` / `Load` / `LoadRepo` (walks up to go.mod),
`Doc.Section(level, title)`, `Section.Subsections()` (next level only),
`Section.Tables()` (header + separator, fences opaque, ASCII art with
pipes ignored), `SplitRow` (a `|` inside a code span or `\|` stays in
the cell), `CodeSpans` (CommonMark run matching + one-space padding
rule, so `` `` Esc ` `` `` works). Its own tests cover fences (including
an unclosed one and `~~~` inside ```), ragged rows, the escaped pipe,
and the go.mod walk-up both ways.

### README.md

- **`### The ≡ menu, row by row`** (after Hotkeys): one `####` table per
  ≡ section (`File`, `File ▸ Compare`, … `AI ▸ Copilot`, `Tools ▸
  Plugins`, `Quit`), columns Row | Key | What it does. Row = every form
  the label takes, each in backticks, `<…>` for the varying part
  (`Tool windows… (<n> shown)`, `Theme: <name>…`). Key = the menu's hint
  verbatim (`esc o / alt+←`, `` `` esc ` `` ``). Intro names the pinned
  top zone and the two user-owned groups (plugin commands, custom
  actions), which are not pinned.
- **Tool-window table** in `### Tool windows`: Tool window | Default
  edge | Opens with, one row per `toolDefs` entry.
- **`## Configuration (config.json)`** (before Project layout): every
  key with values (default first) and what it sets, `"termdock"` marked
  retired, plus a line on the other `~/.config/ced/` files.
- Development section says which tables are test-pinned; Project
  layout lists `internal/readme/`.
- Fixed: the Themes section called the palette `Esc-a` (it's `Esc k`).

### Tests

- `TestREADME_MenuReferenceListsEveryRow` + `TestReadmeLabelPattern`
  (app_test.go). Dynamic rows: label resolved on a fresh test App and
  matched against the cell's forms; an EXACT form beats a `<…>` form, so
  `Open in terminal` and `Open in $EDITOR` share a section safely; more

- `TestREADME_ToolWindowTableListsEveryTool` (toolwindow_test.go): title

- Each failure mode was confirmed by mutating the README (removed row,
  stale row, wrong key hint, empty description, wrong edge, misspelled

## Decisions

- **Reference tables, not "mentioned somewhere".** A substring check
  over the whole README would pass on any stray phrase ("New folder" in
  unrelated prose) and could never detect a stale row. A table per
  surface gives both directions and is what a reader scans anyway.
- **README forms with `<…>` over a test-side name map.** A map keyed by
  action code pointer would have been deterministic but splits the doc
  name from the doc; the forms live where the reader sees them. Only the
  fresh-App form is verified — environment-dependent labels are covered
  by listing both (`Open in Finder` / `Open file manager`), and
  `newTestApp` empties `editorEnv`, so `Open in $EDITOR` is stable.
- **Key column = the menu's hint verbatim** (lowercase `esc`), not the
  hotkey table's `Esc`: the table mirrors the menu, and case-folding
  would hide an `m`/`M` mistake.
- **Order not pinned** — membership + key only, to keep the friction of
  reordering rows low.
- Left alone: the "Stop Soft Wrap" README wording is right — the
  right-click menus use title case (softwrap.go), the ≡ row sentence case.
- `gofmt -l` flags `userconfig_test.go`'s `TestLoadTerminal` map
  alignment, `openfile_test.go` and `findalllive_test.go` — pre-existing,
  not touched.
