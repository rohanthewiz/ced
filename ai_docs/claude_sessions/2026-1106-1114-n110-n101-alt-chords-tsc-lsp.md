## N-112 — a failed restart explains itself (`c1b45d7`)

Raised from the N-101 probe: ced dropped the handshake error, so tsls's
clear refusal never reached anyone.

- `lspServer.explainStart` is armed ONLY by ≡ Code "Restart language
  server" (`menuRestartLSP`, after the missing-binary check).
- `lspExitEvent.err` is set by both start-failure posts in
  `lspEnsureStarted` (spawn error, initialize error).

  bare report can land first and must not use up the flag.
  `handleLSPReady` clears it.

  vscode-languageserver's "Request initialize failed with message: ", and
  makes paths under the root relative.

  the key words at the end. In the real binary it was cut at "provide"

  Precedent: a failed git command opens the info modal.
