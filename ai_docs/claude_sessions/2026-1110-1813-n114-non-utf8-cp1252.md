## The decision

N-114: editing a file that isn't valid UTF-8 rewrote that line's high
bytes as U+FFFD (the `[]rune` conversions in buffer.go), and auto-save
persisted it. Four options were put to the user:

1. **Decode as Windows-1252, re-encode on save** (Vim's
   `fileencodings=…,latin1`) — chosen.
2. Open such files read-only — needs a gate on ~12 mutation paths, more
   work than the decode, and can't fix a typo.
3. Byte-preserving escapes (Emacs raw bytes, via the Private Use Area in
   Go) — a pure Latin-1 file shows a marker per accented letter, and a
   typed é goes in as UTF-8, silently mixing encodings.
4. Auto-save off + warning (the item's original stopgap) — an explicit
   save still wrote U+FFFD.

The reason (1) is safe for ANY bytes: the WHATWG windows-1252 table maps
all 256 byte values to distinct runes (0x81 0x8D 0x8F 0x90 0x9D → their
C1 runes), so decode-then-encode is the identity. Sub-decision: an
explicit save holding a character the code page can't write OFFERS to
convert ("Save as UTF-8?") rather than Vim's plain refusal.

## What changed

- **`internal/editor/encoding.go`** (new): the table, `decodeCP1252` /
  `encodeCP1252`, `*UnencodableError` (rune, 0-based line/col; Error()
  phrased for a flash), `EncodingLabel`, `RuneLabel`, exported
  `DecodeBytes` (detect), `DecodeAs` (known encoding), `EncodeAs`,
  `EncodeLossy` (git's eyes only), `Tab.Unencodable()` (memoised on
  EditRev + encoding), `Tab.ConvertToUTF8()` (dirty +
  `ForgetSavedText`, no undo step, no EditRev bump), `IsControlRune` /
  `controlStandIn`.
- **fileio.go / tab.go**: `diskRead.encoding`; `readTextFile` decodes
  LAST (BOM / CRLF steps are ASCII); `encode()` and `EncodedBytes()`
  return an error, encoding first on the LF text so positions count the
  buffer; `Tab.Encoding` set by NewTab, Reload (re-detected), both
  ReloadAsEdit branches. Render paints C0 / DEL / C1 as one-cell
  stand-ins (`␛`, `▯`) — U+0090 / U+009D are DCS / OSC in 8-bit form.
- **`internal/app/encoding.go`** (new): `offerUTF8Save` (confirm, Yes =
  convert + resume the caller's gesture, tab by pointer),
  `askConvertToUTF8` (≡ row + status door; arms auto-save after a
  convert), `encodingStatusSegments` (` · cp1252`, red `cp1252 ✗` alert
  badge), `statusAlertStyle`, `decodeDiffLine` / `decodeHunkBodies`.
- Wiring: saveTabAt and menuSaveAndClose ask; autoSaveTab skips an
  encoding refusal silently; `dirtyBufferOverlay` returns an error and
  Paste / Copy to… refuse before their flash (and before Copy to…'s
  create-folder confirm); statusSegment gained `alert`; handleGitDiff
  decodes hunk bodies; blame sends `blameContents`; `readCompareFile`,
  `chatFSRead`, `attachContent`, `readContextLines`, and
  `search.searchFile` decode via `editor.DecodeBytes`;
  `formatFileInPlace` refuses non-UTF-8; ≡ File "Convert file to
  UTF-8…" after Validate file.
